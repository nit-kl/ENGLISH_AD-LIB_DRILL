# ADR-0001: アーキテクチャ決定記録（ADR）の運用

## ステータス

Accepted

## コンテキスト

本格開発では技術選定・トレードオフを後から追えるように残す必要がある。

## 決定

- 重要な技術判断は `docs/adr/` に番号付き Markdown で記録する
- フォーマット: タイトル、ステータス、コンテキスト、決定、結果、代替案
- 実装と矛盾した場合は新しい ADR で supersede する（古い ADR は削除しない）

## 結果

- レビュー・オンボーディングが容易になる
- AI/人間どちらの開発でも判断根拠を共有できる
